# This dashboard is not meant to be found by searching. It is not secret --
# every figure on it is already redacted of hostnames, addresses and people --
# but there is no reason for it to turn up in results.
#
# Crawling is ALLOWED on purpose. To keep a page out of an index you must let
# the crawler fetch it, because the instruction not to index lives in the page
# (a robots meta tag) and in the X-Robots-Tag response header. Disallowing the
# fetch hides those instructions, and a URL somebody linked can then still be
# listed -- bare, with no way to tell the engine to drop it.
#
# Cloudflare serves a managed robots.txt when the origin has none, and that one
# declares search=yes. This file exists to say otherwise.

User-agent: *
Content-Signal: search=no, ai-train=no, ai-input=no
Allow: /
